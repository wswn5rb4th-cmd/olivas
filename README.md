# Olivas — Caderno de Coquetelaria

PWA responsivo em português do Brasil, feito com HTML, CSS e JavaScript puro. O app guarda os dados do cardápio neste dispositivo e oferece consulta ao catálogo IBA, destilados e provas aleatórias.

## Publicação

O GitHub Actions publica automaticamente o conteúdo de `outputs/` no GitHub Pages a cada atualização na branch `main`.

## Desenvolvimento local

Abra `outputs/index.html` para uma prévia rápida. Para testar instalação e suporte offline, sirva a pasta `outputs` por HTTPS ou por um servidor local, por exemplo `python -m http.server 8000`.

Consulte `outputs/LEIA-ME.md` para detalhes de uso, backup e fontes.
